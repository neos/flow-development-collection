`TASK: Drop overridden constructors for `TestCase` again <https://github.com/neos/flow-development-collection/pull/3638>`_
--------------------------------------------------------------------------------------------------------------------------

They were removed in 26b8b110a, but a later Rector run re-added them (``ParentTestClassConstructorRector`` from ``PHPUnitSetList::PHPUNIT_100`` targets ``TestCase`` subclasses without a ``Test`` suffix).

``TestCase::__construct()`` is final since PHPUnit 12.1, so loading ``PersistenceTestPHP8`` breaks the functional test bootstrap with "Cannot override final method". The override also replaced the test method name with the class name.
